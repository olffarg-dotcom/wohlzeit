# Wohlzeit – Zeit für dich

Web-App mit kurzen Routinen, Training, Entspannung, Musik und Rezepten. Alle Daten bleiben auf dem jeweiligen Handy.

## Einmalig: Auf GitHub Pages veröffentlichen
1. Auf github.com anmelden, oben rechts auf „+“ und dann „New repository“.
2. Name: `wohlzeit`, Sichtbarkeit „Public“, auf „Create repository“ tippen.
3. Auf „uploading an existing file“ klicken und **alle Dateien aus diesem Ordner** hineinziehen (nicht den Ordner selbst). Unten „Commit changes“.
4. Im Repository: „Settings“ › „Pages“ › bei „Branch“ `main` und `/ (root)` wählen › „Save“.
5. Nach ein bis zwei Minuten ist die App erreichbar unter `https://DEIN-NUTZERNAME.github.io/wohlzeit/`.
6. Diesen Link an Freunde schicken. Android: in Chrome öffnen, „App installieren“. iPhone: in Safari öffnen, Teilen › „Zum Home-Bildschirm“.

## Updates
- Im Repository „Add file“ › „Upload files“, die neuen Dateien hineinziehen (überschreibt die alten), „Commit changes“.
- Die installierten Apps laden die neue Version beim nächsten Öffnen mit Internet automatisch.
- Wichtig: Nutzername und Repository-Namen nie ändern. Eine neue Adresse wäre für die Handys eine neue App, die gespeicherten Daten wären dort nicht vorhanden.

## Sprache
Die App gibt es auf Deutsch und Englisch in derselben Datei. Beim ersten Start richtet sie sich nach der Sprache des Handys (Deutsch bei deutschem Handy, sonst Englisch). Umschalten: Mehr › Sprache / Language. Die englische Fassung ist maschinell übersetzt. Für englische Ansagen braucht das Handy eine englische Stimme.

## Daten
- Gespeichert wird im Browser-Speicher des Handys: Verlauf, Kraft-Tagebuch, eigene Routinen, Einstellungen und Darstellung. Sicherung: in der App unter „Mehr“ › „Daten sichern“.

## Internetradio und eigene Musik
- Die Radiosender werden direkt bei den Anbietern abgerufen. Ändert ein Sender seine Adresse, bleibt er stumm, bis die Adresse in der App angepasst ist. Für mehrere Sender sind Ersatzadressen hinterlegt.
- Eigene Musik: Die Dateien bleiben auf dem Handy und werden nicht hochgeladen. Je nach Browser muss der Ordner nach einem Neustart der App neu gewählt werden.
